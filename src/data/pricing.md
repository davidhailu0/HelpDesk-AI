# Pricing and Plans

## Section 1: Free Tier

Our Free Tier allows developers to explore the platform at no cost.  
It includes up to **1,000 API requests per month**, community support, and access to core documentation.  
This plan is ideal for testing and small-scale personal projects.

## Section 2: Pro Plan

The **Pro Plan** costs **$29/month** and provides **100,000 API requests per month**, priority email support, and access to advanced analytics.  
Teams that need higher limits and performance should start here.

## Section 3: Enterprise Plan

For large organizations, we offer an **Enterprise Plan** with custom pricing.  
It includes unlimited requests, a dedicated account manager, SLA-backed uptime, and on-premise deployment options.  
Contact sales for more details.
